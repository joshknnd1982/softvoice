SoftVoice for NVDA (svWebspeak, self-contained edition)

An NVDA driver for SoftVoice, the formant speech synthesizer that shipped with the pwWebSpeak talking web browser in the mid-to-late 1990s. This version supports higher sample rates, uses 16-bit audio, and has no character limit.

The engine (SVCTL32.DLL, dated 18 August 1997) is a 32-bit i386 library. NVDA 2026.1 is the first 64-bit release and cannot load it in-process; 2025.3 and earlier are 32-bit and could. This add-on always runs the engine in a small dedicated host process anyway, and streams the rendered audio back to NVDA over a loopback socket, so there is a single code path on every supported version. NVDA plays the audio through its own WavePlayer, so output device selection, audio ducking and speech cancellation all behave normally.

All 20 SoftVoice personalities are available in both English and Spanish, with a selectable sample rate up to 22050 Hz.

Fully self-contained — no registry, nothing to install by hand

The 1997 build of SoftVoice is licence-gated. Unlicensed, it does not refuse to speak — it silently truncates every utterance to a single buffer, about 0.4–0.7 seconds. The original release worked around this by shipping a sv_license.reg file that the user had to merge into the Windows registry (HKEY_LOCAL_MACHINE\SOFTWARE\SoftVoice\ProdWorks) before installing the add-on.

This edition needs none of that. The shipped SVctl32.DLL and svwebspeak-host.exe are patched so the engine registers itself in-process, using the same registration number the .reg file carried. Nothing is ever read from or written to the Windows registry, and there is no .reg file to import. Install the add-on and it simply works — including on a machine that has never had SoftVoice on it.

See How the self-contained build works at the end for the technical detail.

Requirements

  • NVDA 2019.3 or later (tested through 2026.1, 32-bit and 64-bit)
  • Windows 10 or 11

Installing

Open the svWebspeak-*.nvda-addon file and answer the prompts, or use NVDA menu → Tools → Add-on store → Install from external source. After NVDA restarts, choose it under NVDA menu → Preferences → Settings → Speech → Change.

Settings

Every parameter below appears in NVDA's Speech settings, and the ones marked ★ are also on the settings ring (NVDA+Control+arrows) so you can reach them from the keyboard without opening a dialog.

SettingWhat it does
VoiceSwitches between SoftVoice's 20 voice personalities.
Rate ★Maps to the engine's 20–500 range; 50% is its natural speed.
Pitch ★Relative to the selected voice — 50% is that voice's own pitch.
Volume ★0–100.
Inflection ★Pitch range / expressiveness (SVSetF0Range).
LanguageEnglish or Spanish, switched live without restarting the engine.
Sample rate ★8000, 11025 or 22050 Hz (default). Applied at the next pause in speech.
Glottal source ★Excitation waveform: Standard, Soft, Rounded, Open, Relaxed, Bright, Buzzy, Harsh, or the voice's own default.
Intonation ★Normal, Monotone or Expressive, or the voice's own default.
Voicing ★Normal, Soft or Whispered, or the voice's own default.
Gender ★Vocal-tract model: Male, Female or Neutral, or the voice's own default.
Breathiness ★Level of breath (aspiration) noise.
Roughness ★Random jitter in the fundamental frequency; a little sounds less mechanical.
Vowel length ★Scales vowel duration; 50% is the engine's natural value.

Pitch is deliberately relative. Each personality is a complete preset with its own pitch, so applying one absolute value to all of them would flatten Child, Colossus and Choir Boy into the same voice. The glottal source, intonation, voicing and gender settings each start on Voice default, which leaves the selected personality's own value untouched until you deliberately change it.

Troubleshooting and debug logging

If speech ever fails, set the environment variable SVWEBSPEAK_DEBUG=1 before starting NVDA. The driver then writes a plain-text log of everything it does — host startup, the engine init handshake, the registration result, parameter changes, recoveries and errors — to svwebspeak-debug.log in your Windows temp folder (%TEMP%). The same events are also written to NVDA's own log at the Info level. Errors are always logged regardless of the setting.

To set the variable for your account: press Windows+R, run rundll32 sysdm.cpl,EditEnvironmentVariables, add a new user variable named SVWEBSPEAK_DEBUG with value 1, then restart NVDA.

Updates

Automatic update checking is off by default in this edition, so an update can never silently replace the patched, registry-free binaries. Two items are added to NVDA's Tools menu:

ItemNotes
Check for svWebspeak updates...Checks immediately and reports the result either way.
Check for svWebspeak updates automaticallyOpt in to a daily check; the setting persists.

Updates are fetched from this project's own repository, not the original upstream, so a check never pulls a build that would reintroduce the registry requirement.

How the self-contained build works

Two tiny binary patches remove the registry dependency without altering any speech code:

  • svwebspeak-host.exe no longer reads SV_KEY from the registry; it supplies the registration number directly to the engine.
  • SVctl32.DLL's SVRegister function no longer reads HKLM\SOFTWARE\SoftVoice\ProdWorks; it goes straight to the engine's own validation of that number, which then unlocks full-length audio.

The net effect is exactly what merging sv_license.reg used to achieve, except it all happens inside the add-on's own process and touches nothing on the system.

Building the add-on

The add-on is a zip archive with manifest.ini at the root, renamed to .nvda-addon. The patched SVctl32.DLL and svwebspeak-host.exe, together with SVENG32.DLL (English voice data) and Svspan32.dll (Spanish voice data), live in synthDrivers/svWebspeak/. Drop Svspan32.dll and the add-on quietly falls back to English only.
